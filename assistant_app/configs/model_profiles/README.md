# 助手模型选择目录

工厂试用菜单仅展示已登记的轻量多模态与阿里云备用服务。默认`ALLOW_BASE_PREVIEW=false`时，不自动暴露磁盘上的独立9B基座或base profile；旧预览ID也不能再提交。权重保留不删除。离线开发工具如需基座对照，仍须服务端明确开启已有预览开关，不改变当前工厂菜单。

阿里云读图问答需要Qwen-VL类视觉理解模型。`qwen-image-*`是图像生成/编辑，`qwen-mt-image-*`是图片翻译，`wan*-video*`是视频生成，不能仅因控制台分类“视觉模型”或有按张免费额度就替换当前严格JSON读图组件。型号、接口、输出模态、额度和地域需分别核对；本轮继续使用已验证的qwen3-vl-plus，未把任何图片/视频生成型号接入问答接口。

前端输入框右下方的菜单读取后端注册的模型选项，分为阿里云、本地微调、本地原始模型。这里仅放服务端连接描述；**不放API Key，不接受访客指定端点或服务器路径**。

现有 `.env` 中的获准连接自动作为默认选项，无需把凭据复制到JSON。当前是阿里云百炼的文字+视觉组合。

统一权重目录由 `ASSISTANT_MODEL_DIRECTORY` 指定，默认项目的 `models/`。目录读取不加载权重、不下载、不启动训练或GPU服务。支持：

```text
models/
  Qwen3.5-9B/                         # 也可以直接放基座目录
  base/Qwen3.5-9B/                    # 当前项目布局
  base/Qwen3-VL-8B-Instruct/           # 图片识读组件，不冒充文字聊天选项
  finetuned/Qwen3.5-9B-cosmetics/<run_id>/
    run-manifest.json                 # 训练来源，必须与基座一致
    assistant-verification.json       # 沿用既有核验报告
    adapter/                         # 或完整merged/
```

本地模型只有文件存在不代表可用。原始模型检查必要元数据与权重分片，微调模型继续使用已有产物核验；还须有明确、实际在线的推理端点及served model名称。模型未启动显示“待部署”，产物未核验显示“待核验”，不会切回云端代答。旧27B Adapter不能直接给9B使用。

自动发现默认连接本机5101文字和5102视觉，可通过 `ASSISTANT_LOCAL_TEXT_MODEL_BASE_URL` / `ASSISTANT_LOCAL_VISION_MODEL_BASE_URL`、相应的 `_SERVED_MODEL` 和 `_API_KEY` 配置。每个模型有不同端口、别名或独立部署时，将本目录 `.json.example` 复制成新的 `.json`，填写实际路径/端点/别名。示例文件本身不会被加载。相对路径以项目根目录解析；目录不放任何虚构产物。

自定义JSON的 `id` 必须唯一，`category` 为 `cloud` / `local_base` / `local_finetuned`。云端条目继承服务端已批准的云端凭据；本地条目使用本地端点凭据，且只允许Settings中的受控主机。增加新的云端模型也必须先由后台明确登记，页面不列出整个付费供应商目录。

修改后点选择菜单中的“刷新模型列表”即可重读，最长默认缓存8秒。选择随每条请求提交，仅影响当前访客后续请求；后台冻结当次模型标识、版本和连接，不改变其他访客或已排队任务，不把密钥写入任务快照。飞书仍使用后台配置的默认服务，本网页的选择不改变飞书机器人。
