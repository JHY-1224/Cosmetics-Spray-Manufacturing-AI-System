## 统一提示词与特殊情况（用户明确要求）

阿里云、轻量Qwen、未来更大Qwen共用同一份服务端策略包：`assistant_app/backend/runtime_prompts.py`统一提供文字SYSTEM、图像VISION及版本/SHA256，模型选择只改变推理端点与产物，不分叉提示词。当前共同候选为`industrial-assistant-v3`，正文位于`assistant_app/configs/policies/shared-{text,vision}-v3.txt`。三类路由的实际请求构造替身测试均校验相同正文和元数据；不以替身测试冒充真实模型通过。

特殊情况按属性区分：已给的量/单位保留；未知只限实际缺项；原文冲突保留两方；完整教学假设可计算，缺局部信息仍完成可得部分；比例基准、物理符号含义、单位尺度和业务状态不能混同。候选v5在选定20题由原Adapter的5/20改善到16/20，但仍把单位尺度与是否取绝对值混为未知、把明确克数的单位说成缺失，未通过，不直接部署、不继续堆叠逐题答案。

未来知识库也经同一资料边界接入：只引用实际返回的片段，保留来源、版本、适用范围、有效性及冲突；检索内容不能覆盖系统规则、冒充现场事实或授予审批/执行权限。现在尚未接入检索，不能声称已查知识库。当前不下载新模型、不改为模型各用一套提示词。

旧`backend/prompts.py`仅作为不可改写的V2历史训练/冻结评测合同保留；它不是另一个模型模式的在线策略。原数据和旧评测不重写为新策略结果，历史数据生成器不能直接当当前共享策略训练集。新训练须另建版本并显式记录共享策略哈希。

共同新策略的选定20题保守通过16题。仍发现“变为4倍”写成“增加4倍”、把复测样本不足当实际缺陷成因、把根因确认当结案必要条件等。代码和数据容器正确不代表小模型已遵守业务边界；后续训练只能作为有证据的新候选实验，不能宣称已唯一确定“训练不够”这个根因。

`prepare_shared_policy_view.py`已新增并验证：新456条视图只替换为当前共同SYSTEM，保留原问题及全部答案/EOS目标；旧数据不动，96条预留原样复制，预留/错误账本的答案不进入监督。新数据在`data/text-training/shared-policy-20261027-v4`，训练SHA`51c19475808772e9936def832977c5b6be1c6fcd1318724fcf6bcaadb9a689b2`。预留题已经影响策略选择，不能再叫独立于策略开发的保留集。正式新训练前仍须云端原生分词、collator、EOS与padding检查，另开run；比较共享策略输入对齐及训练强度，保留中间与最终产物。

## 本轮目标与统计口径

- 用户于 2026-10-27 明确：轻量 Qwen 仅供实验试用，本次整题通过率 **严格超过 90%** 即可。
- 固定测量范围：18 道应用开发题 + 96 道参数分离的同源教学预留题，共 114 题，至少 103 题通过。训练样本回放不计入这个分母。
- 数值、单位、关键事实、权限结论及公式与结果矛盾按整题失败；措辞冗余单独记，不把错误公式因最终数字正确而算通过。
- 完整 114 题现已生成并经助手保守复审：**79 通过、35 失败，69.30%，未达到目标**。18 应用开发题 14/18，96 同源预留题 65/96。114 次均正常 stop、无截断，这不是内容通过率。
- 前 62 题初审曾报 56/62（90.32%），仅筛了已输出内容错误，漏计 4 道开发题的实质核对项；完整复审补入，初审文件保留并明确由完整评审取代。经验：先覆盖全部任务家族，再逐项核对冻结要求，不能把顺序前缀或“没说错但漏关键点”当最终成功。
- 上述预留题与训练题共享任务家族；一旦用于选择策略，就不能再宣称独立于策略开发。封存题、独立现场资料及图像/多轮/稳定性分别验收。
- 当前测量配置：9B Adapter `20261027-134240-499467`、BF16、vLLM 0.22.1、文本候选策略 v4。该策略未通过，不接入云端正式服务，不据此追加训练。

## 接下来的优化顺序

1. 固定114题已审完，完整结论在`reports/9b-cause-20261027-v1/v4-full-content-review.json`。已定位集中于未知量和来源状态，不能接受v4。
2. 针对共性机制做小规模、单因素对照：明确百分数基准与计算中间量、结果代回原式、表格保留行列映射与冲突。只有实测有效才接入应用。
3. 完整回归确认超过 90% 后，冻结可复现策略与推理配置，再验证双模型驻留、图片/多图/多轮、超时恢复和重启。5001 在云端运行。
4. 若通用策略和输入修正后仍达不到目标，再依据已核对标签和失败分布决定新的训练方案；新 run 保留旧权重、数据和报告。
5. 更大配置的后续训练使用经人工复核且授权的训练池；已经用于评估的原题继续留在评估池，另采不同来源/参数的训练资料，不直接把预留答案回灌。
